# Первый прогон ВКР на реальных Book-Crossing CSV (14.10.2026)

Статус: **проверенные результаты одного фиксированного исследовательского прогона, не итоговая серия экспериментов ВКР**.

## Первичные данные

Два полученных CSV: `BX-Books.csv` и `BX-Book-Ratings.csv`. Исходные файлы не публикуются в открытом GitHub.

- Книжных строк: **271 379**. Исправлено чтение backslash-экранированных кавычек (`escapechar='\\'`): без него pandas пропускал 19 записей. Исходный CSV имеет непустые названия книг.
- После нормализации ISBN обнаружена одна повторная запись (ISBN с завершающим табуляционным символом): **271 378 уникальных ISBN**.
- Оценок всего: **1 149 780**; нулевых (неявный сигнал): **716 109**; явных 1–10: **433 671**.
- Явных оценок, сопоставленных с валидными ISBN из таблицы книг: **383 853**; остальные 49 818 явных оценок не вошли в выборку, поскольку соответствующие ISBN отсутствовали в нормализованных метаданных.
- До ограничения выборки: 329 365 train и 54 488 test; split до построения графа по положительным оценкам ≥7, фиксированный seed=42.

## Основной граф и модель

Параметры ограничений: до 1 000 пользователей и 5 000 книг, выбранных **только на основе train**. После фильтрации 990 пользователей, 5 000 книг, 1 709 авторов, 431 издательство. **8 130 узлов, 47 432 ребра** (37 432 rated, 5 000 written_by, 5 000 published_by). Train 37 432, test 5 920. Жанров пока **0** — необходимо подтверждённое внешнее обогащение.

Node2Vec: dim=64, walk_length=20, num_walks=4, epochs=3, p=q=1, seed=42. Взвешенные случайные блуждания второго порядка с кэшированными вероятностями, Word2Vec с однопоточным обучением и стабильным хешем. Для расчёта рейтингов ограничены потоки BLAS.

На проверенной машине: полная процедура **41,91 с**, этап обучения **10,38 с**, максимальная память процесса **534 372 КиБ (~522 МиБ)**. Производительность зависит от аппаратной среды.

## Книга → книга: контрольный proxy на предпочтениях

По ранее положительно оценённым книгам пользователя предсказываются отложенные положительные книги, train-оценки пользователя исключены из кандидатов. Обе модели оцениваются на одинаковых кандидатах. Покрытие исходными книгами 904/905 = **99,89%**.

| Метрика | Node2Vec | Metadata/Jaccard |
|---|---:|---:|
| P@5 | 0.0186 | 0.0214 |
| P@10 | 0.0148 | 0.0164 |
| R@10 | 0.0281 | 0.0339 |
| NDCG@10 | 0.0262 | 0.0303 |
| P@20 | 0.0108 | 0.0112 |
| MRR@20 | 0.0525 | 0.0610 |

В этом опыте Jaccard лучше Node2Vec по NDCG@10; это зафиксированное наблюдение, а не повод изменять результаты. Протокол оценивает косвенную полезность рекомендаций по предпочтениям, **не независимую экспертную оценку сходства книжных пар**.

## Объяснения

Для демонстрационной книги `book:0002251760` («The Forgetting Room: A Fiction (Byzantium Book)») 10/10 первых рекомендаций имели допустимые пути при варианте кратчайшего объяснения. Этот пример **не равен покрытию всего каталога**. Для информативного поиска в 10/10 выдач достигался бюджет обхода; нельзя утверждать глобальную оптимальность таких путей.

## Проверки и ограничения

- Локальная проверка на синтетическом наборе: 36 тестов. GitHub Actions: **36 tests passed**, и отдельный **Streamlit AppTest — success**.
- Реальный граф, эмбеддинги, отчет и тестовые данные сохранены локально; `src.vkr_dashboard.load_dashboard_assets` проверил согласованность узлов и SHA-256.
- **Один seed и один набор параметров** — это первичная проверка, не законченная оценка устойчивости.
- Для честного подбора гиперпараметров нужен train/validation/test, где итоговый test не участвует в настройке.
- Нет подтверждённых жанров, ещё не проведены полные исследования faithfulness, качества объяснений и браузерная проверка на реальном датасете.
