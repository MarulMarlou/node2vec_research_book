# ВКР — парная проверка устойчивости rerank на независимом split=2082

**Дата анализа:** 10 ноября 2026 года.  
**Основание:** три реально полученных локальных файла `explanation_study_report(4).json`, `explanation_validation_grid(4).csv`, `explanation_test_paired_deltas.csv`. Исходные CSV пользовательских оценок и индивидуальные метрики **не опубликованы** в Git. Это анализ исходных результатов пользователя, а не повторное обучение на GitHub Actions.

## Краткий результат

На validation (80 пользователей) по NDCG@10 выбрана **`shortest + rerank, α=0,5`**, NDCG@10 **0,058416**. На независимом test (80 пользователей) выбранный rerank получил **0,032821** против **0,028946** у предопределённого posthoc, относительная разница **+13,39%** (абсолютная `Δ=+0,003876`). Однако **95%-й парный bootstrap-интервал ΔNDCG@10 = [−0,001410; +0,009562] включает ноль**. Следовательно, преимущество по главной метрике **не подтверждено статистически** в принятой условной схеме bootstrap; отрицательные/нулевые эффекты в пределах интервала допустимы. Это не доказательство равенства методов и не отрицание наблюдаемого положительного среднего.

Объяснимость обоих подходов почти полная: **99,625%** posthoc и **100%** rerank в top-10; в этом пилоте изменение покрытия **+0,375 процентного пункта**, а не крупное абсолютное улучшение. Информативный поиск **не усекался** на рассматриваемых validation top-10.

## 3. Test: таблица парных эффектов

| Метрика | Posthoc | Rerank α=0,5 | Δ (rerank – posthoc) | Условный 95%-й bootstrap CI Δ |
|---|---:|---:|---:|---|
| **NDCG@10** | 0,028946 | **0,032821** | **+0,003876** | **[−0,001410; +0,009562]** |
| Precision@10 | 0,01375 | **0,01875** | +0,00500 | [+0,00125; +0,01000] |
| MRR@10 | 0,042530 | **0,044157** | +0,001627 | [−0,019777; +0,017798] |
| Покрытие объяснениями | 0,99625 | **1,00000** | +0,00375 | [0,00000; +0,00875] |

**Пользовательская неоднородность важнее одной средней величины:**
- По **NDCG@10:** 7 пользователей улучшились, 4 ухудшились, **69 не изменились**.
- По **Precision@10:** улучшение у 4, ухудшений нет, **76 без изменений**.
- По **MRR@10:** 7 улучшений, 4 ухудшения, **69 без изменений**.
- По покрытию: 3 улучшения, 0 ухудшений, **77 без изменений**.
- У **66 из 80 пользователей** не было ни одного релевантного попадания в top-10 **ни в одном из двух методов** (`NDCG@10=0` в обоих). Лишь 14 имели ненулевой NDCG хотя бы в одном режиме. Это резко ограничивает практический эффект текущего ранжирования и указывает на необходимость изучить максимальную достижимую полноту отобранного candidate pool.

Интервал Precision@10 строго выше нуля в данном условном bootstrap, однако только **4 из 80** пользователей получили прирост; в отсутствие поправок на множественные метрики/повторяющиеся эксперименты, вариации splits и дополнительной выборки недопустимо заявлять глобальную статистическую значимость качества системы.

## 4. Научная интерпретация

**Корректная формулировка для текста ВКР:** «В эксперименте на фиксированном ограниченном графе знаний и 80 тестовых пользователях объяснимое переранжирование, параметры которого выбраны по validation, улучшило средний NDCG@10 относительно posthoc на 0,003876 (13,39% относ.). Однако 95%-й парный bootstrap-интервал разности [−0,001410; +0,009562] включает нулевой эффект. Следовательно, в этих условиях статистически подтверждённого повышения основной метрики не установлено; эффект неоднороден и у 69 из 80 пользователей NDCG@10 не изменился».

Это **не** проверка причинности доказательных путей: faithfulness исследуется отдельно удалением train-фактов и переобучением. Пользовательская положительная оценка 7–10 — surrogate релевантности, а не экспертная оценка семантического сходства книг. Набор до 150 пользователей и 1000 книг, candidate pool 25 и `random`-разделение без временного порядка не отражают эксплуатационный масштаб.

Интервалы считаются **условно для одного split, model seed, отбора 80 пользователей и фиксированной модели**. Они не покрывают вариации эмбеддингов и разные подграфы. Повторное использование этой же test-выборки для будущего подбора α недопустимо.

## 5. Что исследовать дальше

1. **Оценить candidate-recall ceiling:** для каждого пользователя вычислить, есть ли хотя бы одна test-положительная книга среди полного доступного каталога, среди выбранных 25 кандидатов и среди top-10; без этого нулевые показатели 66/80 интерпретировать трудно. Разделять ограничения candidate generation и reranking.
2. **Зафиксировать итоговый оценочный протокол до нового test:** несколько независимых split и, по возможности, разные seeds обучения; заранее закрепить выбор α на validation, учитывать парность по пользователям, не проводить итоговую оптимизацию на test.
3. **Вернуться к незакрытому требованию первого этапа:** получить и вручную проверить доступные жанровые факты с provenance, долю покрытия, затем отдельную абляцию «с жанрами/без жанров» на одинаковом holdout.
4. **Подготовить материалы итоговой ВКР:** графы/схемы по нормам кафедры, реальные скриншоты интерфейса, таблицы измерений и ограничения, независимую проверку понятности объяснений пользователями.

**Необходимых новых реальных результатов по жанрам и полному candidate-recall в предоставленных трёх файлах нет; эти значения нельзя подставлять из предположений.**
