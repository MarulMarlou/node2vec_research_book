# ВКР — этап 2: рекомендации и первые графовые объяснения

Статус: исследовательский **прототип**, не окончательная ВКР.

## Изменения

- `src/vkr_recommend.py`: новая воспроизводимая реализация Node2Vec с weighted second-order random walks (p/q) и Word2Vec Skip-gram/negative sampling; один worker и заданный seed; сохранение и чтение эмбеддингов; поиск близких книг по косинусу; контрольный **book-to-book** метод на пересечении признаков автора/издательства/жанра (Jaccard); отдельно — **user-to-book** holdout метрики с исключением всех обучающих взаимодействий из выдачи.
- `src/vkr_explain.py`: два метода: поиск кратчайших допустимых путей и ранжирование по значимости типов узлов, редкости признака и длине пути. Разрешены проверяемые пути из 2 и 4 рёбер вида книга–автор/издательство/жанр/читатель–книга; для читателя учитываются только оценки >=7. Формируются фактологические русские объяснения, а также сведения об использованных рёбрах и их источниках. Ограничиваются число кандидатов и расширений поиска, с флагом `truncated`.
- `src/vkr_pipeline.py`: последовательность подготовки, обучения на train-графе, оценки по test, book-to-book примера и сравнения двух методов объяснений и двух режимов выдачи (posthoc и rerank). Имеется отдельный контрольный metadata baseline.
- `tests/test_vkr_recommend_explain.py`, `tests/test_vkr_pipeline.py`: 13 новых проверок, включая синтетический сквозной запуск (всего с этапом 1 — 19 тестов).

## Установка и запуск

Нужны Python, `pandas`, `networkx`, `numpy`, `gensim`, `pytest`. Установка по `requirements.txt` (для тестов может потребоваться отдельно `python -m pip install pytest`).

```bash
python -m pytest -q tests/test_vkr_foundation.py tests/test_vkr_recommend_explain.py tests/test_vkr_pipeline.py
python -m src.vkr_pipeline --raw-dir data/raw --processed-dir data/processed --results-dir results
```

Исходные файлы `BX-Books.csv` и `BX-Book-Ratings.csv` скачать отдельно; они в `.gitignore`. Дополнительный файл жанров передаётся параметром `--genre-csv data/raw/book_genres.csv` со столбцами `isbn,genre,source_url`. Без внешнего источника жанров соответствующее требование диплома **не выполнено**.

Новый запуск пишет `results/metrics/vkr_pipeline_report.json` и `results/embeddings/vkr_n2v.npy`. Старые результаты `all_experiments.csv` не перезаписываются.

### Что означают метрики

**Precision@k, Recall@k, F1@k, NDCG@k и MRR** из нового прототипа измеряют только восстановление *отложенных положительных оценок пользователей* (**user-to-book**, threshold 7). Разделение делается **до построения графа**. Из выдачи исключаются обучающие рейтинги; в отчёте указывается покрытие пользователей. АUC-ROC намеренно не вычисляется без явно определённого набора негативных примеров.

**Book-to-book рекомендации** и пояснения демонстрируются отдельно; показатели user-to-book **не доказывают** точность book-to-book. Для ВКР требуется экспериментально определить релевантность пар книг или обосновать протокол на основе пользовательского взаимодействия.

Контрольное сравнение для book-to-book пока проводится с Jaccard по книжным атрибутам, что допустимо в ТЗ вместо TransE. Старую реализацию TransE не меняем и не используем для новых выводов.

### Ограничения, оставшиеся задачи

1. Исходные реальные Book-Crossing CSV и внешние жанры недоступны внутри этого запуска: локальные тесты проведены на **синтетических данных** (19 passed); итоговые численные научные результаты отсутствуют.
2. У информативного поиска ограниченные бюджеты `max_paths=200`, `max_expansions=5000`, поэтому `truncated=true` означает, что лучший в полном графе путь не гарантирован. Для финальной ВКР нужно сравнить скорость и полноту поиска.
3. В оценке путь из 4 рёбер является семантически допустимой цепочкой, но не причинным доказательством рекомендационного скоринга Node2Vec.
4. **Faithfulness**-эксперимент (удаление объясняющих рёбер, повторное обучение с теми же настройками/seed, изменение score/rank) пока не проведён.
5. Экспериментальные сравнения на фиксированных книгах, исследование коэффициента `alpha`, полноценный Streamlit UI, рисунки подграфов и пользовательское исследование впереди.
6. Текст, таблицы и значения из предыдущей курсовой автоматически не включаются в исследовательские результаты ВКР.

Для следующих экспериментов рекомендуется хранить сведения о конфигурации, seed, окружении, времени обучения и составе выборки; оценивать несколько seed, а также ввести CI в GitHub Actions и проверку совместимости с поддерживаемой версией Python.
