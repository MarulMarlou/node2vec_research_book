# Третий этап ВКР: результаты первых опытов по объяснимости и faithfulness

**Дата:** 10 ноября 2026 года. **Источник:** пять пользовательских материалов: PCA-скриншот, \`explanation_validation_grid.csv\`, \`explanation_study_report.json\`, \`faithfulness_pairs.csv\`, \`faithfulness_report.json\`. Все числовые данные ниже перепроверены по CSV/JSON. Файлы содержат отдельные экспериментальные прогоны, **не один и тот же split и не одну и ту же модель**. Исходные пользовательские взаимодействия не публикуются в Git.

## 1. PCA: проверенная функция визуализации

На присланном скриншоте видно, что вкладка двумерного распределения эмбеддингов в Streamlit работает: авторы, книги, издательства и пользователи различаются цветами, выбранные книги выделены увеличенными маркерами. Значения объяснённой дисперсии PC1 и PC2 **не видны на снимке**, поэтому пока не приводятся. Сильно вытянутые направления и визуальное перекрытие точек не являются ни подтверждением качества рекомендаций, ни доказательством семантических кластеров.

**Требование для отчёта ВКР:** сохранить полноценный скриншот вкладки с дисперсией PC1/PC2, легендой и указанием параметров модели, а также отдельно приложить визуализацию истинного графового объяснения. Не смешивать PCA-точки с KG-рёбрами.

## 2. Проверка эксперимента shortest/informative и rerank

| Максимальная длина пути | **2 ребра** |

На validation проверено **8 настроек постобработки одной заранее обученной модели**, а не 8 отдельных запусков Node2Vec: два метода объяснения и \`posthoc\` или \`rerank\` с α=0,2 / 0,5 / 0,8. Числовые колонки CSV и JSON совпадают с погрешностью округления.

### Результаты validation

| Метод/режим | α | Precision@10 | NDCG@10 | Покрытие объяснениями top-10 |
|---|---:|---:|---:|---:|
| Shortest / Posthoc | 0 | 0,01000 | **0,026947** | 88% |

| Informative / Rerank | 0,2 | 0,00500 | 0,013744 | **99%** |
| Informative / Rerank | 0,5 | 0,00500 | 0,013744 | **99%** |
| Informative / Rerank | 0,8 | 0,00500 | 0,008671 | **99%** |

Относительно posthoc режим rerank при α=0,2 **увеличил покрытие на 11 процентных пунктов**, одновременно снизив validation NDCG@10 на ~49,0%. Это **обмен объяснимости на качество в фиксированном пилоте**, а не доказанный универсальный эффект.

Все \`shortest\` и \`informative\` совпали по метрикам при одинаковых режимах: при \`max_depth=2\` могут выбираться **только пути одинаковой длины**, а оба метода сортируют двухрёберные пути по информативности. Сравнения действительно *разных по длине* маршрутов ещё не произошло. Все объяснённые пути имели среднюю длину 2; частота усечения поиска нулевая. Поэтому нельзя писать «методы эквивалентны вообще».

По фиксированному правилу выбора на validation победил \`shortest + posthoc\`, α=0. На **однократно просмотренном test** для 20 пользователей: Precision@5=0,0300; NDCG@5=0,03456; **Precision@10=0,0200**, **NDCG@10=0,033914**, MRR@10=0,071667, NDCG@20=0,045170, **покрытие объяснениями=87,5%**; средняя длина подтверждённого пути 2, усечений 0, среднее время поиска ~0,628 мс на элемент. У выбранной модели \`test_selected\` совпадает с фиксированным контролем \`test_posthoc_control\`, поскольку selected сам есть posthoc.

**Ограничения:** 20 пользователей — мало; удержанные пользователи выбираются из пригодных для оценки, а не представляют всех; измеряется **book→book preference proxy** по оценкам пользователей, не экспертная семантическая похожесть книг. Новый эксперимент depth-4 должен использовать **новый split**: test=2042 теперь уже просмотрен и не должен повторно служить основой для настройки.

## 3. Faithfulness: подтверждённый пилот с двумя парами

Отдельный \`faithfulness_report.json\`: текущий \`quick\` граф **1 695 узлов и 7 874 ребра**, Node2Vec dim=32, walk_length=15, num_walks=3, epochs=2, p=q=1, window=5, model seed=42. От предыдущего эксперимента по объяснениям эти параметры и граф отличаются. Изучено **две** рекомендованные книги для одного источника. У обоих объяснения были длиной 2 и состояли из **двух фактов \`rated\`** (совместные оценки одного пользователя). Удалены только факты обучающего графа. Переобучение **неизменённого** графа полностью воспроизвело исходные cosine score.

| Показатель | Пара 1 | Пара 2 |
|---|---:|---:|
| Исходный cosine | 0,992721 | 0,992515 |
| Cosine после удаления пути | 0,980313 | 0,987504 |
| Уменьшение cosine | **0,012409** | **0,005011** |
| Исходное место | 4 | 10 |
| Место после удаления | 533 | 241 |
| Изменение ранга | **+529** | **+231** |
| Среднее уменьшение cosine в контролях | 0,002581 | 0,003437 |
| Успешных контролей | 2/2 | 2/2 |

У первой пары observed drop оказался примерно в 4,81 раза больше контрольного среднего, у второй — в 1,46 раза. Это не коэффициент причинности и не статистический эффект. Данные согласованы между JSON/CSV, отсутствующих эмбеддингов не было.

**Ключевая методологическая оговорка:** даже небольшой абсолютный сдвиг cosine может вызвать большой скачок места, если оценки очень близки. Переобучение после изменения train-графа воздействует на систему случайных блужданий и на все векторы. Два случайных контрольных удаления каждого пути учитывали только число рёбер и тип \`rated\`, **но не степень узлов**, и их недостаточно для статистической проверки. Удалённые факты *связаны* с изменением рекомендации, однако нельзя считать доказанным, что именно они были её уникальной причиной.

## 4. Исправленный протокол для следующих опытов

После анализа этих результатов в \`src/vkr_faithfulness.py\` добавлены:
- **relation- и приблизительно degree-matched** контроли: сохраняется тип отношения, число удаляемых рёбер, исключаются вершины исходного объяснения, по возможности выбираются рёбра с близкими \`log(1+degree)\` обоих концов;
- все **индивидуальные** значения изменений cosine для контролей (не только mean), средний штраф несовпадения степеней и разница observed-drop vs control-mean;
- прежний отчёт из двух пар **не переинтерпретируется** как результат улучшенного протокола — его нужно повторить.

В \`src/vkr_explanation_study.py\` будущая серия дополнительно будет вычислять на независимом test **лучший rerank, заранее выбранный на validation**, даже если глобальный победитель — posthoc. Это позволяет проверить trade-off на test, не оптимизируя α по test. Новый режим \`explanations-depth4\` использует **отдельный split seed=2052**, \`max_depth=4\`, 40 пользователей и отдельную папку \`results/explanation_study_depth4/\`; данные предыдущего эксперимента не перезаписываются.

## 5. Научный статус

Результаты пригодны для оформления **пилотного раздела** ВКР с визуализациями, таблицами и ограничениями. Для убедительного исследования нужны более крупная выборка пользователей, пути длины 4, повторные seed, degree-matched контроли и confidence intervals. Жанровые факты всё ещё не получены и не верифицированы для реального обучающего графа. Даже после новых тестов заявлять о причинной объяснимости без статистических проверок нельзя.
