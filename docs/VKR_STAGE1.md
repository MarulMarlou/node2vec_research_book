# ВКР — этап 1: подготовка типизированного графа и тестовой выборки

Это **изолированный новый контур** подготовки данных. Устаревшие модули
`src/data_loader.py`, `src/metrics.py`, `src/run_experiments.py` и
`src/app.py` не изменены. Результаты старых экспериментов из
`results/metrics/all_experiments.csv` пока не подтверждены: старая оценка
выполняла разделение train/test после обучения на полном графе.

## Запуск

В каталоге `data/raw` необходимо разместить оригинальные
`BX-Books.csv` и `BX-Book-Ratings.csv`. Эти файлы исключены из GitHub.
Используются `pandas` и `networkx`; тесты запускаются через `pytest`.

```bash
python -m pip install -r requirements.txt
python -m pytest -q tests/test_vkr_foundation.py
python -m src.vkr_prepare --raw-dir data/raw --processed-dir data/processed
```

Опциональное обогащение жанрами: CSV `isbn,genre,source_url`, где ссылка
на источник обязательна; допускается несколько жанров для одной книги:

```bash
python -m src.vkr_prepare --genre-csv data/raw/book_genres.csv
```

**Важно:** программа не ищет и не проверяет внешние жанры самостоятельно.
Без CSV с жанрами требование ТЗ о жанрах не выполнено.

## Сохранённые материалы

- `data/processed/vkr_train_ratings.csv`: обучающие явные оценки;
- `data/processed/vkr_test_ratings.csv`: отложенные положительные оценки;
- `data/processed/vkr_knowledge_graph.graphml`: ориентированный
  `MultiDiGraph`, узлы book/user/author/publisher/genre, связи rated,
  written_by, published_by, has_genre, метаданные provenance
  (`source_file`, `source_row`, `source_url`);
- `data/processed/vkr_node2vec_graph.graphml`: упрощённая
  неориентированная проекция, **не заменяющая** исходный граф для объяснений;
- `data/processed/vkr_preparation_report.json`: статистика подготовки.

`source_row` обозначает номер разобранной CSV-записи с учётом заголовка;
если источник содержит пропущенные/многострочные записи, физическая строка
может отличаться.

## Протокол

1. Читаем метаданные книг и явные оценки 1–10. Оценка 0 в Book-Crossing —
   неявный сигнал, не отрицательная оценка; в этой версии исключена.
2. Положительной считаем оценку >=7. Для пользователя с двумя и более
   положительными оценками откладываем детерминированное подмножество в
   test, сохраняя хотя бы одну положительную оценку в train.
3. Популярных пользователей и книги выбираем **только из train**, по
   умолчанию max_users=1000 и max_books=5000.
4. Строим граф из train и метаданных. Test-рёбра rated не добавляем.
5. Новые Node2Vec/TransE-модели в дальнейшем необходимо обучать только
   на новых обучающих файлах, а не на старом графе.
6. `src/vkr_metrics.py` считает метрики одной выдачи из переданного
   списка положительных меток; он **не определяет** book-to-book ground
   truth, выбор кандидатов, пользовательскую агрегацию или протокол оценки.

## Оставшиеся вопросы

- Настоящий датасет Book-Crossing здесь **не запускался**: проверены
  только синтетические тесты, 6 успешных.
- Не реализована автоматическая загрузка жанров из Open Library/Wikidata.
- Нельзя смешивать метрики user-to-book и book-to-book без единого
  экспериментального протокола.
- Не проверены качество транслитерации, дубли ISBN/изданий и внешние факты.
- В train пока сохраняются рейтинги 1–6 и их веса. Для Node2Vec
  надо сравнить эту схему с графом только положительных взаимодействий.
- Интеграция с исходным обучением, Streamlit и explainability выполняется
  следующим этапом. Старые значения метрик не используются как доказательство.
