# Предыдущая исследовательская версия: разграничение с новой ВКР

Репозиторий начинался как исследовательский проект с экспериментацией над Node2Vec/TransE. Позже в отдельной ветке `feature/vkr-stage1-typed-graph-holdout` появился **новый независимый контур ВКР** с train/test до построения графа, типизированными отношениями, воспроизводимым Node2Vec и графовыми объяснениями.

Старые файлы **сохранены для истории разработки**; они не являются инструкцией к исполнению первых этапов новой ВКР.

| Унаследованное содержимое | Назначение |
|---|---|
| `src/convert.py`, `src/data_loader.py`, `src/simple_node2vec.py` | Предыдущее преобразование данных, граф и простая реализация Node2Vec |
| `src/transe_runner.py` | Прежняя реализация TransE, **не интегрированная** в новый `src/vkr_embedding_study.py` |
| `src/run_experiments.py`, `src/experiments.py`, `src/analyze_results.py` | Предыдущие экспериментальные сценарии и анализ |
| `src/app.py` | Прежний интерфейс; актуальный интерфейс — `src/vkr_app.py` |
| `requirements.txt` | Зависимости старого исследования; для ВКР используются `requirements-vkr-core.txt` / `requirements-vkr-app.txt` |
| `run_full_experiment.bat`, `run_full_experiment.sh` | Унаследованные сценарии запуска; актуальный Windows-скрипт — `scripts/run_vkr_windows.ps1` |
| Уже сохранённые `results/metrics/*.csv` и `results/plots/*.png` | Исторические результаты, **не используемые в качестве научного подтверждения новой ВКР** |

В предыдущем исследовательском конвейере встречалось разделение обучающего и тестового набора **после обучения на полном графе**. Поэтому старые численные метрики нельзя без отдельной перепроверки переносить в ВКР как корректные оценки качества на отложенных данных. Наличие файлов со словами `transe` или изображений «сравнения эмбеддингов» **не означает**, что новое исследование Node2Vec против TransE уже выполнено на едином typed KG и сопоставимом holdout.
