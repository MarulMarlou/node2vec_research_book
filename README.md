# Рекомендательная система книг на основе графа знаний

**Исследовательский прототип ВКР — первые два этапа разработки.**

Реализована подготовка данных [Book-Crossing](https://grouplens.org/datasets/book-crossing/), построение типизированного графа знаний и обучение эмбеддингов **Node2Vec**. Дополнительно доступна демонстрация рекомендаций похожих книг с графовыми объяснениями в Streamlit.

> **Состояние на 14 октября 2026 г.** Первый этап выполнен в части подготовки исходных данных и построения графа; внешнее жанровое обогащение ещё не завершено. Второй этап содержит работающий Node2Vec, первичные замеры и сценарий train/validation/test; интеграция TransE и полноценная сравнительная серия остаются в работе. **Это не окончательные результаты всей ВКР.**

## Быстрый запуск на Windows

Требуются **Python 3.11**, Git, исходные `BX-Books.csv` и `BX-Book-Ratings.csv`. Python 3.15 не используется: зависимости зафиксированы и проверены на 3.11.

Если вы ещё не склонировали репозиторий:

```powershell
git clone --branch feature/vkr-stage1-typed-graph-holdout --single-branch https://github.com/MarulMarlou/node2vec_research_book.git
cd node2vec_research_book
```

Поместите файлы в `data/raw/BX-Books.csv` и `data/raw/BX-Book-Ratings.csv`. Исходные пользовательские рейтинги **не включены в Git**. Источник и описание набора — [GroupLens, Book-Crossing](https://grouplens.org/datasets/book-crossing/). Перед использованием проверьте условия распространения оригинального набора.

```powershell
py -3.11 --version
powershell -ExecutionPolicy Bypass -File .\scripts\run_vkr_windows.ps1 -Mode quick
powershell -ExecutionPolicy Bypass -File .\scripts\run_vkr_windows.ps1 -Mode app -SkipInstall
```

После запуска Streamlit откройте **http://localhost:8501**. Не закрывайте терминал с работающим сервером.

Режимы запуска:

| Режим | Назначение | Примечание |
|---|---|---|
| `quick` | Построение небольшого графа, обучение, метрики, аудит | До 150 пользователей, 1 000 книг |
| `main` | Основной исследовательский подграф | До 1 000 пользователей, 5 000 книг |
| `tests` | Автоматические тесты нового контура ВКР | Нужны установленные зависимости |
| `app` | Интерфейс рекомендаций | Сначала выполните `quick` или `main` |

**Эксперимент с выделенной validation-выборкой** запускается отдельно (не переписывает артефакты основного интерфейса):

```powershell
.\.venv-vkr\Scripts\python.exe -m src.vkr_embedding_study --mode quick --max-users 150 --max-books 1000
```

Расширенная сетка `--mode full` содержит 12 конфигураций Node2Vec × 3 фиксированных seed (36 запусков) и может быть ресурсоёмкой. **Это не сравнение с TransE**, предусмотренное дальнейшим этапом.

Полная пошаговая инструкция для получателя: **[docs/VKR_WINDOWS.md](docs/VKR_WINDOWS.md)** или [QUICK_START.md](QUICK_START.md).

## Что уже подтверждено на реальных данных

| Сценарий | Подтверждённый результат |
|---|---|
| Основной исследовательский граф | 8 130 узлов, 47 432 ребра, 5 000 книг |
| Основной Node2Vec (одна конфигурация) | NDCG@10 = 0,0396 для **user→book** |
| Косвенный book→book preference proxy | NDCG@10: Node2Vec = 0,0262; metadata/Jaccard = 0,0303 |
| Локальный Windows `quick` | 1 695 узлов, 7 874 рёбер; `audit_passed: true`; обучение 2,01 с |
| Локальный Windows `quick`, user→book | Precision@10 = 0,0385; NDCG@10 = 0,0632 |

Результаты `quick` и `main` получены с **разными размерами выборок и параметрами** — их нельзя интерпретировать как честное сравнение моделей. Значения book→book основаны на восстановлении отложенных пользовательских предпочтений, а **не на экспертных метках семантического сходства**. Первая версия графа не содержит внешних жанров. Подробная методика и ограничения: [отчёт о данных](docs/VKR_REAL_BOOK_CROSSING_2026-10-14.md).

## Архитектура актуальной ВКР

| Компонент | Назначение |
|---|---|
| `src/vkr_prepare.py` | Чтение CSV, очистка, разбиение до построения графа, typed KG и проекция |
| `src/vkr_graph_audit.py` | Проверки типов, связности, распределения степеней, происхождения рёбер и утечек test |
| `src/vkr_recommend.py` | Node2Vec, сохранение эмбеддингов, поиск похожих книг |
| `src/vkr_embedding_study.py` | Независимые train/validation/test, подбор параметров по validation |
| `src/vkr_book_eval.py` | Косвенный контроль book→book на отложенных предпочтениях |
| `src/vkr_explain.py` | Кратчайшие и информативные пути, posthoc и rerank |
| `src/vkr_pipeline.py` | Сквозной запуск подготовки, обучения, оценки и демонстрации |
| `src/vkr_app.py`, `src/vkr_dashboard.py` | Веб-интерфейс и проверка соответствия артефактов по SHA-256 |
| `tests/test_vkr_*.py` | Регрессионные и сквозные тесты нового контура |

## Важное разграничение со старой версией

Репозиторий унаследовал от предыдущей курсовой/исследовательской работы файлы `src/convert.py`, `src/simple_node2vec.py`, `src/transe_runner.py`, `src/app.py`, `run_full_experiment.bat`, `requirements.txt`, а также старые `results/metrics` и `results/plots`. Они **не входят в актуальный подтверждённый конвейер ВКР**, могут использовать иной протокол оценки и не должны служить доказательством её нынешних результатов. Смотрите [описание прежних материалов](docs/LEGACY_PROJECT.md).

Исходные данные и создаваемые в ходе новых запусков пользовательские оценки, модели и отчёты не публикуются. Автоматическая проверка проекта выполняется GitHub Actions на Python 3.11; браузерная проверка на компьютере получателя проводится отдельно.
