# Техническое описание актуального конвейера ВКР

**Версия:** ветка `feature/vkr-stage1-typed-graph-holdout`, 14.10.2026.  
**Основная точка входа:** `scripts/run_vkr_windows.ps1` или `python -m src.vkr_pipeline`.  
**Техническая задача:** рекомендательная система книг на основе типизированного графа знаний Book-Crossing, Node2Vec и объясняемых рекомендаций.

> Документ описывает **текущий** контур ВКР. Исторические скрипты исходной курсовой находятся в том же репозитории, но имеют отдельные зависимости и протокол оценки; они не используются для подтверждения приведённых здесь результатов. См. [документ об архиве](docs/LEGACY_PROJECT.md).

## 1. Конвейер обработки данных

```text
BX-Books.csv + BX-Book-Ratings.csv
                │
                ▼
        src/vkr_prepare.py
        очистка ISBN, фильтрация оценок 0,
        train/test до обучения
                │
                ├──> vkr_train_ratings.csv / vkr_test_ratings.csv
                ├──> vkr_knowledge_graph.graphml (MultiDiGraph)
                └──> vkr_node2vec_graph.graphml (неориентированная проекция)
                               │
                               ▼
                      src/vkr_recommend.py
                      Node2Vec + Word2Vec
                               │
          ┌────────────────────┴───────────────────────────┐
          ▼                                                ▼
   src/vkr_book_eval.py                              src/vkr_explain.py
   proxy-метрики user preference                     проверяемые пути по KG
          │                                                │
          └────────────────────┬───────────────────────────┘
                               ▼
                  src/vkr_app.py / src/vkr_dashboard.py
                  рекомендации, сравнение, визуализация
```

Отдельный научный сценарий `src/vkr_embedding_study.py` заново разбивает исходные оценки на **train, validation и test**. Эта схема предназначена для выбора параметров, и её метрики нельзя объединять с обычным `vkr_pipeline` без указания различий разбиения.

## 2. Состав модулей

| Файл | Функция | Выход |
|---|---|---|
| `src/vkr_prepare.py` | Разбор latin-1/semicolon CSV с экранированными кавычками; очистка метаданных, детерминированное разбиение, нормализация, KG | CSV train/test, два GraphML, отчёт подготовки |
| `src/vkr_graph_audit.py` | Доли типов узлов/отношений, компоненты связности, степени; проверка соответствия рёбер train и отсутствия test в графе | `results/metrics/vkr_graph_audit.json` |
| `src/vkr_recommend.py` | Взвешенный Node2Vec второго порядка (параметры p/q), кэш вероятностей переходов, однопоточный Skip-gram, косинус | `results/embeddings/vkr_n2v.npy`, `vkr_n2v_ids.json` |
| `src/vkr_embedding_study.py` | Train/validation/test, перебор конфигураций, выбор по validation NDCG@10 и контрольный test | `results/study/embedding_experiments.csv`, `study_report.json`, selected_embeddings |
| `src/vkr_book_eval.py` | Proxy релевантности похожих книг из отложенных положительных оценок, Jaccard baseline | Метрики и покрытие в JSON |
| `src/vkr_explain.py` | Допустимые пути книга–признак/читатель–книга, минимальная длина и информативность; posthoc/rerank | Фактологический текст, путь, ссылки на рёбра, признак усечения поиска |
| `src/vkr_pipeline.py` | Сквозной демонстрационный сценарий, вывод независимых user→book и book→book proxy метрик | `results/metrics/vkr_pipeline_report.json` |
| `src/vkr_dashboard.py` | Проверки хешей и соответствия моделей данным, подготовка выдачи и пути для визуализации | API функций интерфейса |
| `src/vkr_app.py` | Streamlit: поиск книги по ISBN/названию, рекомендации, два вида объяснений и сравнение | Локальный веб-интерфейс |
| `tests/test_vkr_*.py` | Unit, синтетические интеграционные и Streamlit AppTest проверки | Статус GitHub Actions |

## 3. Модель данных

Узлы `book:<ISBN>`, `user:<User-ID>`, `author:<...>`, `publisher:<...>`; при подключении подтверждённых жанров — `genre:<...>`.

Типизированные связи: `rated` (читатель → книга), `written_by` (книга → автор), `published_by` (книга → издатель), при обогащении `has_genre` (книга → жанр).

Для каждого ребра сохраняется provenance в виде `source_file`, `source_row` и при наличии `source_url`. Оригинальный ориентированный `MultiDiGraph` используется при объяснениях, неориентированная взвешенная проекция — **только для Node2Vec**.

Нулевая оценка Book-Crossing означает неявное взаимодействие, а не отрицательный рейтинг, поэтому из обучающих явных оценок исключена. Положительные тестовые предпочтения — рейтинги **≥ 7**. Обучающий граф не содержит рёбер из test; это проверяется аудитом.

## 4. Оценка и воспроизводимость

- `src/vkr_pipeline.py`: базовый демонстрационный train/test; размеры и seed фиксируются аргументами командной строки.
- `src/vkr_embedding_study.py`: выделенный test не используется при выборе гиперпараметров; сначала выбирается конфигурация по **validation NDCG@10**, затем один раз рассчитываются итоговые test-метрики.
- Рекомендации **user→book** оцениваются отдельно от **book→book preference proxy**.
- Metadata/Jaccard — контрольный алгоритм **без графовых эмбеддингов**; он не заменяет требуемое сравнение с TransE.
- Время обучения зависит от компьютера; отчёты отдельно фиксируют параметры, результаты и SHA-256 исходных файлов. Гарантируется воспроизводимость процедур/seed, но не универсальное совпадение измерений времени.
- На реальном основном графе 8 130 узлов и 47 432 ребра; исследование по нескольким seed и методам ещё не завершено. См. [зафиксированный отчёт](docs/VKR_REAL_BOOK_CROSSING_2026-10-14.md).

## 5. Новый сравнительный конвейер для второго этапа стажировки

Дополнительно к Node2Vec реализованы:

- `src/vkr_transe.py` — новая реализация TransE поверх **актуального типизированного train-графа**. В отличие от исторического `src/transe_runner.py` использует текущие IDs и типизированные отрицательные примеры; скоринг пользователь–книга учитывает вектор отношения `rated`.
- `src/vkr_compare_embeddings.py` — независимый **head-to-head** сценарий Node2Vec и TransE с одинаковым train/validation/test, отложенными высокими/низкими явными оценками, AUC-ROC и MRR по k=5/10/20, сохранением параметров, времён и результатов моделей.
- `tests/test_vkr_transe.py`, `tests/test_vkr_compare_embeddings.py` — детерминизм, отсутствие утечек, типы negative sampling, AUC на явных метках и синтетическая сквозная оценка.

Windows: `-Mode compare-quick` (4 пробных запуска) или `-Mode compare-full` (42 сравнительных запуска). Артефакты — `results/comparison`, исключены из Git. **Факт выполнения всех 42 реальных запусков пока не подтверждён.** См. [полный аудит исходных требований](docs/VKR_REQUIREMENTS_AUDIT_2026-10-28.md).

## 6. Ограничения текущей версии

- Не завершено обогащение **достоверными жанрами** из внешних источников (в стандартном Book-Crossing нет жанров).
- Исторический `src/transe_runner.py` не является новой интеграцией TransE; нет сопоставимой научной серии Node2Vec против TransE на этом же typed KG и holdout.
- Не выполнены исследования faithfulness путём удаления рёбер и **повторного обучения** эмбеддингов.
- Путь объяснения — достоверная связь по графу, но не доказательство причинного влияния именно этой связи на cosine Node2Vec.
- Скриншоты браузерного приёмочного теста на Windows и экспертное исследование понятности объяснений пока не включены.
